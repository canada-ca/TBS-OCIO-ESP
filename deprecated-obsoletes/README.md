# Deprecated Government of Canada Technologies

* As of March 31, 2015, the Microsoft XP operating system is discontinued.
* As of July 14, 2017, Windows Server 2003 is discontinued.
* As of December 31, 2017, all versions of the Microsoft Internet Explorer browser software previous to version 11 are discontinued.
* As of March 31, 2019, all versions of the Microsoft Office software including or previous to Office 2010 are discontinued.
* As of March 31, 2019, all versions of Blackberry Messenger, other than Blackberry Messenger Enterprise (BBME) are discontinued.
* As of December 31, 2019, all versions of Microsoft Windows Desktop Operating System previous to Windows 10 are discontinued.
* As of December 31, 2019, Windows Server 2008 is discontinued.
* As of January 1, 2021, use of browser-based Java is discontinued (including Oracle Java 8 SE and older).
* As of October 10, 2022, Windows Server 2012 is discontinued.
* As of April 1, 2021, the use of pager devices is discontinued.
* As of April 11, 2023, SharePoint 2013 is discontinued.
* As of July 14, 2026, SharePoint 2016 is discontinued.
* As of July 14, 2026, SharePoint 2019 is discontinued.
* As of July 11, 2017, Microsoft SQL Server 2012 is discontinued
* As of July 9, 2019, Microsoft SQL Server 2014 is discontinued
* As of July 14, 2026, Microsoft SQL Server 2016 is discontinued

# Technologies obsolètes du gouvernement du Canada

* À partir du 31 mars 2015, le système d’exploitation Microsoft XP est obsolète.
* À partir du 14 juillet 2017, Windows Server 2003 est obsolète.
* À partir du 31 décembre 2017, toutes les versions du logiciel de navigation Microsoft Internet Explorer, antérieures à la version 11, sont obsolètes.
* À partir du 31 mars 2019, toutes les versions du logiciel Microsoft Office, y compris ou avant la version 2010, sont obsolètes.
* À partir du 31 mars 2019, toutes les versions de BlackBerry Messenger, autres que BlackBerry Messenger Enterprise (BBME), sont obsolètes.
* À partir du 31 décembre 2019, toutes les versions du système d’exploitation Microsoft Windows Desktop antérieures à Windows 10 sont obsolètes.
* À partir du 31 décembre 2019, Windows Server 2008 est obsolète.
* À partir du 1er janvier 2021, l’utilisation de Java axé sur les navigateurs est arrêtée (y compris Oracle Java 8 SE et plus ancien).
* À partir du 10 octobre 2022, Windows Server 2012 est obsolète.
* À partir du 1er avril 2021, l’utilisation des pagers est arrêtée.
* À partir du 11 avril 2023, SharePoint 2013 est obsolète.
* À partir du 14 juillet 2026, SharePoint 2016 est obsolète.
* À partir du 14 juillet 2026, SharePoint 2019 est obsolète.
* À partir du 11 juillet 2017, Microsoft SQL Server 2012 est obsolète.
* À partir du 9 juillet 2019, Microsoft SQL Server 2014 est obsolète.
* À partir du 14 juillet 2026, Microsoft SQL Server 2016 est obsolète.
